## Set Up & Run Project

### Install the following:

- **Node.js** (v18 or later recommended)
- **npm** (comes with Node.js)

### Local Set Up:

1. git clone https://github.com/bowenwang0815/SmartPack.git
2. cd SmartPack
3. npm install

### Run:

1. npm run dev
2. Navigate to http://localhost:3000 on your browser.
